こんにちは、ぺーさんです。

「運営1年目シリーズ」の第3回は、記録の話です。前回の請求で、返戻の原因として「請求明細書と実績記録票の不一致」が出てきました。今回は、その手前の、記録そのものを整えます。

記録は、「書いてあるか」だけでなく、「別の書類と食い違っていないか」が問われます。訪問系の事業所は、サービス提供記録、実績記録票、請求データ、勤務の実績が、それぞれ別の場所で作られます。1年目は、この4つが月末に一致するかどうかを、意識的に確認する習慣をつけたいところです。運営指導で指摘されやすい書類については、[運営指導でよく指摘される書類不備トップ5](/blog/unei-shidou-shorui-fubi-top5/)も参考になります。

## 制度の整理：何を、いつ、誰の確認で書くのか

まず事実の部分です。

### 障害福祉サービス（居宅介護など）

厚生労働省の解釈通知には、居宅介護のサービス提供の記録について、次のような趣旨が書かれています（基準第19条の項目）。

- サービスの提供の都度、遅滞なく記録する
- 記録するのは、提供日、提供した具体的な内容（身体介護と家事援助の別など）、実績時間数、利用者負担額など、利用者に伝えるべき事項
- サービス提供の記録について、利用者の確認を得る

実績記録票は、この記録をもとに、報酬の請求の基礎になる帳票です。ある県の資料では、実績記録票のほかに、居宅介護従業者が作成する提供記録など、サービス提供の詳細を記録するものを作成するよう努めることとされています。実績記録票は月ごとの実績の一覧で、提供記録は日々の中身、と使い分けるとイメージしやすいと私は考えています。

実績記録票の様式には、事業者が記入する欄（サービス提供日時、算定時間数、加算の該当など）と、利用者の確認欄があります。厚生労働省の様式では、従来の「利用者確認印」が「利用者確認欄」に改められています。堺市の案内では、確認欄の記載内容は任意で、レ点、〇印、押印、署名などが例に挙がっています。ただし、サービス提供の都度に記録し、その記載内容を利用者に示して確認を受けることが求められています。

**「押印がいらなくなった」と「確認が不要になった」は違います。** 様式が変わっても、利用者に確認してもらう手続きは残っています。

### 介護保険の訪問介護

指定基準（厚生省令）には、サービスを提供したときに、提供日、内容（身体介護と家事援助の別）、保険給付の額その他必要な事項を、居宅サービス計画書などに記載することが定められています。具体的なサービスの内容などの記録も必要です。

実務では、提供日時、サービスの内容、実際の提供時間、担当した訪問介護員の名前、利用者の状態の変化などを記録することが多いです。これらの項目の書き方は事業所ごとの運用で、基準の条文に一つずつ書いてあるわけではありません。

運営指導での指摘例として、特記事項がないと記載されていない、保険給付のサービスと自費のサービスの内容が混在している、といった事例を紹介する資料もあります。

### 保存期間は、自治体で違い得る

| 区分 | 確認できた内容 |
|---|---|
| 介護保険（国の省令） | サービス提供に関する記録は、完結の日から2年間 |
| 介護保険（自治体の条例） | 川崎市は5年と定めている。起算日の考え方も市の資料で示されている |
| 障害福祉 | ある県の資料では、サービス提供記録は5年間の保存義務があり、記録が確認できない場合は報酬の返還を求めることがある、とされている |

**保存期間は、事業所の所在地の条例で確認してください。** 国の基準より長く定めている自治体があります。保存期間より前に処分すると、記録がないことを理由に、請求の根拠が示せなくなるおそれがあります。

## 突合のズレは、どこで起きるのか

「突合」は、複数の書類を並べて、内容が一致するか確かめる作業です。訪問系では、おおむね次の関係になります。

| 書類 | 主に何を示すか |
|---|---|
| サービス提供記録 | 日々の中身（内容、時間、担当者、状態） |
| 実績記録票（障害）、サービス提供票別表（介護） | 月の実績（日・時間・回数）。請求の基礎 |
| 請求データ | 国保連に送る内容 |
| 計画・受給者証・ケアプラン | 決められたサービスの内容・量 |
| 勤務の実績（出勤簿・シフト） | 誰が、いつ働いたか |

ここからは、法令の内容ではなく、私の実務経験にもとづく考えです。ズレが起きやすい場面は、たとえば次のようなところです。

- 後日にまとめて記録票を作り、実際の時間と数分ずれる
- 利用者の都合で、時間が短縮・延長されたが、片方の書類にしか反映されていない
- 同じ日に複数回訪問したときの時間の扱いが、記録票と請求データで違う
- 記録を訂正したとき、訂正前のデータがそのまま請求に使われる
- 記録票の様式や、記録の書き方が、担当者ごとに違う

堺市の手引きは、記録票を修正する場合、新しく作り直すのではなく、もともとの記録票を修正し、修正した箇所について利用者の確認を得る、としています。区の手引きには、後日にまとめて作成した記録は認められない、という趣旨の記載があります。この点の扱いは自治体の手引きを確認してください。

### 仮想の例

たとえば、次のようなズレです（仮想の例です）。

| 項目 | 内容 |
|---|---|
| サービス提供記録 | 10:00〜11:00、身体介護 |
| 実績記録票 | 10:00〜11:30、身体介護 |
| 原因（仮） | 利用者の希望で30分延長したが、提供記録にだけ反映されていなかった |
| 対応 | 実際の時間を担当者に確認し、正しい内容に統一する。利用者の確認を受け直す |

どちらが正しいかを、担当者と利用者の確認で判断することが大切です。書類の整合をとるためだけに、実際と違う内容に直すのは避けてください。

## 月末の確認フロー

私は、次の流れを、日次・週次・月次に分けるとやりやすいと考えています。

| 頻度 | 確認する人 | 内容 |
|---|---|---|
| 日次 | 訪問した職員 | 訪問後に、その日のうちに提供記録を書く。時間の変更は、その場で記録する |
| 週次 | サービス提供責任者 | 記録の書き漏れ、時間の記載、内容の空欄を確認する |
| 月末 | サービス提供責任者と事務 | 記録票を回収し、利用者の確認欄の記入漏れを確認する |
| 翌月1〜3日 | 事務 | 提供記録、実績記録票、勤務実績を並べ、ズレを確認する |
| 請求前 | 管理者 | ズレの解消を確認し、請求データの点検に進む |

月末の3点照合は、次のように短くまとめると続けやすいです。

- [ ] 提供記録の日付・時間が、実績記録票と一致している
- [ ] 実績記録票の時間が、勤務実績と矛盾していない
- [ ] 利用者の確認欄が、すべて記入されている
- [ ] 計画・受給者証の内容を超えていない
- [ ] 訂正した箇所に、訂正の履歴と確認が残っている

## 今日からできること（まず3つ）

1. 自分の自治体の、記録の保存期間と起算日を、条例や手引きで確認する
2. 実績記録票と提供記録の、時間の書き方（開始・終了の時刻、算定の考え方）を、1枚のルールにして全員に共有する
3. 月末の3点照合を、翌月1〜3日の作業として予定表に入れる

## まとめ

記録の整合は、月末にがんばるより、日々の書き方で決まります。「その日のうちに」「事実のとおりに」「訂正は履歴を残して」の3つをそろえれば、突合のミスは大きく減ると私は考えています。記録が整うと、次は「計画とモニタリング」との整合が課題になります。次回は、計画とモニタリングのつながりを取り上げます。
