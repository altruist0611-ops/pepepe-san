こんにちは、ぺーさんです。

日曜日にお届けしている「マネジメントシリーズ」の第2回です。前回はサ責の仕事と、仕事が回らなくなる原因を整理しました。今回は、サ責の大事な仕事のひとつ「新人ヘルパーの育成」です。

訪問介護は、現場に入ったら基本的に一人で動く仕事です。独り立ちまでの手順があいまいだと、新人さんも利用者さんも不安になります。制度で確認できることを整理したうえで、同行訪問から独り立ちまでの進め方の一例をご紹介します。

## 制度面で確認できたこと

### 訪問介護員の資格

埼玉県の新規指定の手引きでは、訪問介護員は、介護福祉士、看護師等、実務者研修修了者、介護職員初任者研修課程などの修了者とされ、生活援助従事者研修の修了者は生活援助中心型のみとの記載もありました。障害福祉サービスの居宅介護などは、従業者の要件が別に定められています。採用時には最新の基準と自治体の案内をご確認ください。

### 研修の位置づけ

- 運営基準（平成11年厚生省令第37号）第30条第3項は、訪問介護員等の資質の向上のために、事業者が研修の機会を確保しなければならないと定めています
- 解釈通知では、研修機関の研修や事業所内の研修への参加の機会を計画的に確保することとされています（自治体掲載の通知で確認。版が古い場合があるため最新版もご確認ください）
- サ責の職務としても、訪問介護員等への研修や技術指導が第28条第3項に挙げられています

### 特定事業所加算で求められる研修計画

東京都が公開している留意事項では、特定事業所加算の体制要件として、訪問介護員等ごと、およびサ責ごとの研修計画の作成が挙げられ、個別具体的な研修の目標、内容、期間、実施時期などを定めるとされています。定期的な会議（おおむね月1回以上）や、文書等による指示と報告も要件です。自治体の資料には、研修計画や実施記録の保存を案内しているものもあります。

### 新人に必ず実施する研修

自治体の集団指導資料では、令和6年4月から義務化された事項として、次のものが挙げられていました。

- 認知症介護基礎研修：資格を持たない従業者が対象で、新たに採用した従業者に、採用後1年を経過するまでに受講させる。看護師、介護福祉士、実務者研修修了者、初任者研修修了者などは受講義務の対象外とされている
- 虐待の防止、感染症対策、業務継続計画に関する研修：年1回以上実施し、新規採用時にも実施する

### 初回加算の「同行」は、新人育成の同行とは別のもの

初回加算は、算定基準（平成12年厚生省告示第19号）で、新規に訪問介護計画を作成した利用者について、サ責が初回の訪問を行った場合や、他の訪問介護員等の訪問にサ責が同行した場合が対象とされています。新規利用者の受け入れに関する規定であり、新人育成の同行そのものを定めたものではありません。

### 障害福祉サービスの「同行支援」

重度訪問介護には、新任の従業者と熟練した従業者が2人で支援する「同行支援」があると、複数の自治体が案内しています。対象となる利用者、新任従業者の条件、時間数の上限、報酬の扱いが細かく決められているため、活用する場合は最新の告示と自治体の案内をご確認ください。

## 労務面：同行訪問の時間は賃金の対象になるか（一般論）

同行の時間を賃金の対象にするかは迷いやすいところです。確認できた範囲で、一般論を整理します。

- 厚生労働省の「労働時間の適正な把握のために使用者が講ずべき措置に関するガイドライン」では、労働時間を「使用者の指揮命令下に置かれている時間」とし、参加することが業務上義務づけられている研修・教育訓練の受講や、使用者の指示により業務に必要な学習等を行っていた時間は労働時間に該当するとしています
- 訪問介護労働者については、平成16年の通達（基発第0827001号）が、研修時間は使用者の明示的な指示に基づく場合は労働時間になるとしています。指示がなくても、受けないと不利益な扱いを受けたり、実質的に出席を強制されたりする場合は労働時間にあたるとされ、この内容は令和3年の介護保険最新情報（Vol.912）でも改めて周知されています
- 介護報酬が算定できるかどうかと、労働基準法上の労働時間かどうかは、別の問題です

以下は私の考えです。事業所の指示で新人さんが同行する時間は、賃金の対象にする前提で設計しておくほうが安全だと考えています。同行の時間の扱いは、雇用契約書や就業規則に書いておくとトラブルを防げます。個別の判断は、社会保険労務士や労働基準監督署にご確認ください。

## 段階的な育成の流れ

ここからは、法令の内容ではなく、私の実務経験にもとづく考えです。同行の回数や日数の決まりは、確認した範囲では見当たりませんでした。「何回同行したら独り立ち」ではなく、「何ができたら次に進む」という基準で考えるのがよいと思っています。

| 段階 | 新人の役割 | 同行者の役割 | 次に進む目安 |
|---|---|---|---|
| 0. 事前の準備 | 基本ルールを学ぶ（守秘、報告、緊急時、感染対策、虐待防止） | サ責が説明し、理解を確認する | 基本ルールを自分の言葉で説明できる |
| 1. 見学 | 観察する。手は出さない | 先輩がケアを行い、意図を説明する | 観察の記録が書ける、質問が出る |
| 2. 一部担当 | 決めた一部の工程を担当する | 先輩が主で、新人の手元を見る | 担当の工程を手順どおりにできる |
| 3. 見守りつきで担当 | 新人が主で行う | 先輩は見守り、必要な場面だけ手を出す | 一連の流れを安全にできる |
| 4. 独り立ち | 単独で訪問する | 訪問前後に電話などでフォロー | チェックリストの必須項目がそろう |

同行を進めるうえでのポイントは、次の3つです。

1. **同行の目的を、訪問の前に決める。** 「今日は見学だけ。気づいたことを最後に3つ教えてください」のように、新人さんに役割を伝えます。
2. **訪問が終わったら、5分だけ振り返る。** 良かった点と、次回の課題を1つずつ確認します。
3. **利用者さんに、同行者が入ることを事前に説明する。** 複数のスタッフが入るため、了承を得てから進めます。

最初の独り立ちは、手順が明確でリスクが比較的低い利用者さんから始めると、負担が小さくなります。

## チェックリストの例

以下は、仮想のチェックシートの例です。段階ごとに、事業所の実態に合わせて項目を増減してください。

| 項目 | 見学 | 一部担当 | 見守り | 独り立ち前 |
|---|---|---|---|---|
| 個人情報・守秘の意味を説明できる | | | | |
| 利用者さんの意向を聞き、声かけができる | | | | |
| 手順書に沿ってケアができる | | | | |
| 転倒しやすい場所や危険を確認できる | | | | |
| 手洗い・手袋など感染対策ができる | | | | |
| 記録を事実にもとづいて書ける | | | | |
| 状態変化やヒヤリハットをすぐ報告できる | | | | |
| 緊急時の連絡先と手順を説明できる | | | | |
| できない依頼を受けたとき、事業所に確認できる | | | | |

各項目は「できた」「一部できた」「これから」の3段階で評価し、コメント欄をつけると課題が見えやすくなります。

## 独り立ちの判断基準

独り立ちの判断は、同行した1人の感覚だけに頼らないことをおすすめします。たとえば、次の条件をそろえます。

- チェックリストの必須項目が、すべて「できた」になっている
- 緊急時の対応と連絡先を、自分の言葉で説明できる
- 同行者とサ責の両方が「単独で入れる」と判断している
- 新人さん本人が「入れる」と話し、不安な点を言葉にできている

最終判断はサ責が担います。独り立ち直後は、訪問後に電話で報告を受け、最初の数回は振り返りの時間を取ると安心です。

## 研修の記録の残し方

研修は、実施しただけでなく、記録が残っていることが大切です。記録は次の2種類を用意すると整理しやすくなります。

**1. 個別の育成計画**
氏名、入職日、目標、内容、予定時期、担当者。加算の研修計画とあわせて作ると二度手間になりません。

**2. 同行記録シート**（仮想の例）

| 項目 | 記載例 |
|---|---|
| 日付・時間 | 何月何日、何時から何時まで |
| 利用者 | 個人名ではなく、事業所内の管理番号 |
| 今日の段階 | 見学／一部担当／見守り など |
| 実施した内容 | |
| できたこと、課題 | |
| 新人さんのコメント | |
| サ責の確認 | 日付と署名 |

保管場所とルールは事業所内で統一し、個人情報を含むため、閲覧できる人も決めておきましょう。

## 今日からできること：まず3つ

1. **独り立ちの基準を、「できること」のリストにする。** まず10項目から始めます。
2. **同行記録シートを1枚つくる。** 毎回の同行の後に、5分で書ける様式にします。
3. **同行の前後に、5分の打ち合わせを入れる。** 「目的」と「振り返り」を決めるだけで、同行の質は変わります。

## まとめ

制度面で確認できたのは、事業者が研修の機会を確保する必要があること、特定事業所加算では個別の研修計画が求められること、初回加算の同行は新人育成の同行とは別であることなどです。同行の回数や日数の決まりは確認できなかったため、事業所ごとに「何ができたら次へ進むか」を決めて運用することが重要です。次回は「シフト作りと急な欠勤への備え」を取り上げます。
