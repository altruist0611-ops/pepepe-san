こんにちは、ぺーさんです。

今回から、指定を受けて開業したばかりの事業所の運営者に向けた「運営1年目シリーズ」を始めます。第1回は、1年目に「初めて」出てくる年間イベントの整理です。

開業前後は、指定申請や人の採用で手一杯です。ところが運営が始まると、毎月の請求に加えて、年に1回だけ来る手続きが、思いがけない月に次々と現れます。「去年もやったから分かる」という経験が使えないのが、1年目の難しさです。

期限の管理表の作り方は、別の回で詳しく書く予定です。今回は表を作る前の段階として、「1年目に何が来るのか」の一覧と、初回に戸惑いやすい点に絞ります。

## 確認できた時期を整理する

まず事実の部分です。日付は令和8年（2026年）に確認できたものです。自治体で違うものは、その旨を書きます。

### 毎月あるもの

| 時期 | 内容 | 確認できたこと |
|---|---|---|
| 毎月1日〜10日 | 国保連への請求 | 前月末までに行ったサービス分を、1日から10日までに請求する（大阪府国保連の案内）。10日を過ぎると当月には受け付けられない |
| 毎月15日ごろ | 報酬の入金 | 請求の翌月15日ごろに支払われるとする自治体の案内がある。国保連ごとの日程表で確認 |
| 毎月15日 | 加算の体制届の目安 | 障害福祉では、15日以前の届出は翌月、16日以降は翌々月から算定とする県の案内がある（詳しくは[開業直後に見落としがちな加算届の期限](/blog/kasan-todokede-kigen/)） |

### 年に1回のもの

| 時期 | 内容 | 確認できたこと |
|---|---|---|
| 4月〜 | 処遇改善加算の計画書 | 令和8年度は、4月算定分は4月15日まで、6月算定分は6月15日までの特例があった。7月以降は、算定する月の前々月末日までとする自治体の案内がある |
| 5月1日〜7月31日など | 障害福祉サービス等情報公表の定期報告 | ある県では、基本情報・運営情報の報告期限が令和8年7月31日。報告期間は都道府県で定める |
| 6月1日〜7月10日 | 労働保険の年度更新 | 令和8年度は6月1日から7月10日まで。概算保険料は前年度の確定保険料をもとに計算し、年度終了後に確定保険料で精算する（厚生労働省） |
| 7月1日〜7月10日 | 社会保険の算定基礎届 | 令和8年度は7月10日まで。4〜6月の報酬が基準。決まった標準報酬月額は、9月から翌年8月までの各月に適用（日本年金機構） |
| 7月10日 | 源泉所得税の納期の特例 | 給与を支払う人が常時10人未満で、承認を受けている場合、1〜6月分の納期限は7月10日、7〜12月分は翌年1月20日（国税庁） |
| 7月末 | 処遇改善加算の実績報告 | 介護保険は、各事業年度の最終の加算の入金があった月の翌々月末日（継続なら翌年7月31日とする東京都の案内）。障害福祉は自治体の案内を確認 |
| 9月ごろ | 介護サービス情報の公表 | 都道府県ごとに異なる。ある県では令和8年に新規指定された事業所は「基本情報のみ」を9月8日〜30日に報告 |
| 12月 | 年末調整 | 毎月の源泉徴収額と、1年間の所得税額を精算する手続き（国税庁） |
| 決算後3か月以内 | 経営情報の報告 | 障害福祉サービスは会計年度終了後3か月以内とする県の案内がある。介護保険も同様の制度があり、介護報酬が100万円以下などは対象外とする都の案内がある |

### 開業や雇用からの「経過」で発生するもの

| きっかけ | 内容 | 確認できたこと |
|---|---|---|
| 指定を受けたとき | 障害福祉サービス等情報公表の初回報告 | 指定を受けた日から1か月以内とする県の案内がある |
| 労働者の雇入れ時 | 雇入れ時の健康診断 | 常時使用する労働者が対象。パートタイム労働者も、常時使用される場合は対象（厚生労働省） |
| 雇入れから1年以内ごと | 定期健康診断 | 1年以内ごとに1回。結果の個人票は5年間保存（厚生労働省） |
| 雇入れから6か月 | 年次有給休暇の付与 | 6か月継続勤務し、全労働日の8割以上出勤した労働者に10労働日。休日と休暇の違いは、求人票シリーズの記事で整理します |
| 年1回以上など | 研修・訓練・委員会 | 頻度はサービスの種類や基準で異なる。虐待防止は[こちら](/blog/gyakutai-boushi-taisei/)、感染症は[こちら](/blog/kansen-taisaku/)、BCPは[こちら](/blog/bcp-sakusei/)。原文と自治体の資料で確認 |

なお、運営指導の時期は事業所ごとに通知されます。指定の更新は6年ごとで、1年目には来ません。

## 月別に並べると

上の表のうち、月が確認できたものだけを暦月に並べました。決算月や指定日で動くものは、自分の事業所の日付に置き換えてください。

| 月 | 確認できたイベント |
|---|---|
| 4月 | 年度替わり。処遇改善加算の計画書（令和8年度の特例は4月15日まで） |
| 5月 | 情報公表の定期報告が始まる県がある（障害福祉） |
| 6月 | 労働保険の年度更新が始まる（1日〜） |
| 7月 | 年度更新と算定基礎届（ともに10日まで）、源泉所得税の納期の特例、情報公表の報告期限、処遇改善加算の実績報告 |
| 9月 | 新しい標準報酬月額の適用開始、介護サービス情報の公表（県による） |
| 12月 | 年末調整 |
| 1月 | 源泉所得税の納期の特例（7〜12月分、20日） |
| 毎月 | 請求（1日〜10日）、入金（15日ごろ）、加算の体制届（15日が目安） |

表にない月は、法定の期限がないという意味ではありません。私が公的資料で確認できたものに、その月の期限がなかったということです。

## 初回に戸惑いやすい点

ここからは、法令の内容ではなく、私の実務経験にもとづく考えです。

1. **7月に3つの手続きが重なる**
 年度更新、算定基礎届、源泉所得税の納期の特例が、いずれも7月10日前後に集中します。最初の年は、6月に入ってから調べ始めると間に合いにくくなります。5月中に、誰が何を作るのかを決めておくと安心です。
2. **開業年度の労働保険は「概算」から始まる**
 保険関係が成立した年度の保険料は概算保険料として納付し、あとで確定保険料として精算するとされています（厚生労働省）。1年目の年度更新は、この精算と次年度の概算が同時に来ます。賃金の集計期間は4月1日から3月31日なので、月ごとの賃金を集計できる形にしておくと作業が楽です。
3. **算定基礎届は「4〜6月」の報酬で決まる**
 対象は7月1日現在の被保険者で、6月1日以降に資格を取得した人などは対象外とされています。開業直後に採用が続いた事業所ほど、誰が対象か迷いやすいところです。
4. **処遇改善加算は「算定する月の前々月末」が起点**
 開業の時期によって、計画書を出すタイミングが変わります。年度の途中で開業した場合の考え方は、[処遇改善加算の取得タイミング](/blog/shogu-kaizen-kasan-taimingu/)で整理しています。
5. **情報公表と経営情報は、忘れやすい**
 決算後3か月以内などの期限は、自分の決算月から逆算しないと分かりません。

## 今日からできること（まず3つ）

1. 決算月と指定日を確認し、上の表を自分の事業所の暦月に置き換えて、紙1枚にする
2. 所轄の都道府県・市区町村の案内で、処遇改善加算の計画書・実績報告と、情報公表の報告期間を確認し、確認した日付を書き込む
3. 5月と12月の予定表に、「年度更新・算定基礎届の準備」と「年末調整の準備」を先に入れておく

税務や社会保険、労働保険の具体的な手続きは、事業所の状況によって異なります。判断に迷うときは、税理士や社会保険労務士、所轄の窓口に確認してください。

## まとめ

1年目は、初めて迎えるイベントが多く、順番も分かりにくい年です。まず「何がいつ来るのか」を1枚にして、全体像をつかむだけで、慌てる場面が減ると私は考えています。次回は、毎月の最大のイベントである「国保連への請求」を取り上げます。
