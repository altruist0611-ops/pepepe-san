こんにちは、ぺーさんです。

「運営1年目シリーズ」の第2回は、毎月の請求業務です。

請求は、事業所にとって収入の入口です。しかも毎月、期限が来ます。1年目の事業所ほど、「請求ソフトに入力すれば終わり」ではなく、その前後の確認作業で差が出ると感じています。

初回入金までの資金繰りは、別の記事 [国保連への請求はいつから始まる——初回入金までの資金繰り](/blog/kokuhoren-seikyu-itsukara/) で書きました。今回は、資金の話ではなく、請求業務の毎月の流れと、返戻・査定を減らす確認のポイントです。

## 毎月の請求の流れ

まず事実の部分です。日程は国保連合会や自治体で異なるため、実際の日付は、所属する国保連の請求・支払の日程表で確認してください。

### 障害福祉サービスの場合

確認できた資料をもとに、流れを整理します。

1. **請求データの作成・送信**：前月末までに行ったサービス分について、毎月1日から10日までに請求する。受付は、電子請求受付システムによる伝送で、1日0時から10日23時59分まで（大阪府国保連の案内）
2. **国保連の審査（一次）と、自治体の審査（二次）**：ある県の国保連の案内では、一次審査が11〜16日ごろ、二次審査が18〜21日ごろとされている。一次審査で登録済みの受給者情報などと照合される
3. **支払**：確定した請求額は、請求の翌月15日ごろに支払われる（堺市の手引き、ある県の国保連の案内）

たとえば9月にサービスを提供した場合は、10月10日までに請求し、11月15日ごろに入金される、という流れです。

請求データの送信後も、10日までは取下げができます。10日を過ぎると、当月の受付はされません（大阪府国保連の案内）。

### 介護保険（訪問介護）の場合

請求受付期間は、毎月1日から10日までです（大阪府国保連の案内）。介護保険では、事業所が出す請求明細書と、ケアマネジャーの事業所が出す給付管理票が、国保連で突合されます（国民健康保険中央会の手引き）。

## 返戻・査定・過誤：言葉の違い

| 言葉 | 意味 |
|---|---|
| 返戻 | 請求内容に誤りなどがあり、事業所に返却されること。その請求分は、支払われない（介護保険の手引きより） |
| 査定 | 請求した分の一部が支払われること。減単位や増単位になった場合（介護保険の手引きより） |
| 保留 | 請求明細書に誤りはないが、給付管理票が未提出などで、支払が行われない状態（介護保険の手引きより） |
| 過誤申立 | いったん支払われたあとで誤りが分かったときに、請求を取り下げる手続き。あとで再請求する |

障害福祉サービスの返戻については、堺市の手引きが「請求内容が不適切な場合や、国保連に登録された事業所情報・受給者情報と請求内容に相違がある場合」に起こるとしています。

過誤申立の期限や、再請求の時期は、自治体や国保連で違います。たとえば、堺市は「同月過誤」で処理し、申立書の提出期限を毎月25日ごろとしています。介護保険では、国保連の手引きに、通常過誤は申立の締切が20日（基準日）、再請求は翌々月10日までの受付、同月過誤は締切が7日、10日までに再請求、と書かれています。**自治体で取扱いが違うため、必ず所轄に確認してください。**

## 返戻になりやすい原因：確認できた範囲

確認できた資料に、次のような例が挙がっています。

- **受給者証の内容との不一致**：支給量の超過、有効期間外の請求、障害支援区分の認定開始日の誤り（堺市の手引き、区の手引き）
- **利用者負担額の超過**（堺市の手引き）
- **請求明細書と実績記録票の不一致**（堺市の手引き）
- **加算の算定基準に合わない請求**：処遇改善加算などで、誤った区分で請求すると請求エラーになるとする自治体の案内がある（大阪市）
- **他の事業所との契約量の合算**：他事業所の契約量を含めた合計で確認が必要とする区の手引きがある
- **請求の操作上のミス**：仮審査エラーを修正したあと、送信済みのデータを取り下げないと、重複エラーとなり全件が返戻される、とある国保連の案内にある

なお、区の手引きの一部は平成25年版など古いものです。現在の様式や運用は、最新の手引きで確認してください。

## 請求前チェックリスト

ここからは、法令の内容ではなく、私の実務経験にもとづく考えです。次のチェックを、毎月同じ順番でやると、返戻を減らしやすいと考えています。

**利用者ごとの確認**

- [ ] 受給者証（介護保険は認定・被保険者証）の有効期間内か
- [ ] 支給量・契約量を超えていないか（他事業所の分も含めて）
- [ ] 負担上限月額や、上限額管理の有無を、最新の受給者証で確認したか
- [ ] 契約書・重要事項説明書・契約内容の報告が、最新の状態か

**実績・記録の確認**

- [ ] 実績記録票の日付・時間が、サービス提供記録と一致しているか
- [ ] 利用者の確認欄が、サービス提供のたびに記入されているか
- [ ] 同じ日に複数回サービスを提供した場合の算定は、正しいか

**加算・体制の確認**

- [ ] 算定している加算の体制届が、受理されているか
- [ ] 処遇改善加算の区分が、届出と請求で同じか

**送信の確認**

- [ ] 送信前に、請求ソフトの点検（エラーチェック）を通したか
- [ ] エラーを修正したあと、送信済みのデータを取り下げたか
- [ ] 送信後に、受付結果を確認したか
- [ ] 代理受領の通知を、利用者ごとに交付したか（堺市の手引きでは、毎月、利用者一人一人に交付が必要とされている）

## 月初10日までの段取り（仮想の例）

締切ぎりぎりに送信すると、エラーが出たときに直す時間がありません。次の表は、あくまで一例です。

| 日 | 作業 | 担当の例 |
|---|---|---|
| 月末 | 実績記録票・提供記録の回収と、記入漏れの確認 | サービス提供責任者 |
| 1〜3日 | 受給者証の確認、実績の入力 | 事務 |
| 4〜6日 | 請求データの作成、エラーチェック、加算の確認 | 事務・管理者 |
| 7日 | 管理者が確認 | 管理者 |
| 8日 | 送信 | 事務 |
| 9〜10日 | 受付結果の確認と、エラーがあった場合の修正・再送信 | 事務 |

請求ソフトのIDやパスワードを紛失した場合、再発行に1週間程度かかるとある国保連が案内しています。10日の直前に気づくと、その月の請求が翌月に延びるおそれがあります。ログイン情報は、月初に一度、確認しておくと安心です。

## 返戻・査定があったときの動き

1. 通知帳票で、対象の利用者と、エラーの理由を確認する
2. 原因が、受給者証、実績記録票、加算のどれにあるかを切り分ける
3. 事業所側の誤りなら修正し、次の請求受付期間に再請求する。支払済みの請求であれば、過誤申立の手続きを確認する
4. 原因を、チェックリストに1行足して、次月から確認する

「同じ返戻を2回出さない」ことが、1年目の目標です。

## 今日からできること（まず3つ）

1. 所属する国保連の、今年度の請求・支払の日程表を確認し、送信の社内締切を「10日の2営業日前」に決める
2. 請求ソフトのIDやパスワード、電子証明書の有効期限を確認する
3. 上のチェックリストを、自分の事業所の言葉に書き換えて、毎月の作業手順にする

## まとめ

請求は、毎月の確認の積み重ねで安定します。返戻の多くは、受給者証の内容、実績記録票、加算の届出という、日ごろの管理と結びついています。次回は、そのうちの「サービス提供記録と実績記録票」を取り上げます。
